# Design: integrate-workbench-macros-and-checksums

## Decisions

| 决定 | 选择 | 理由 |
| --- | --- | --- |
| 主宏库接入 | 读取 `serialscope.macros`，映射为 `legacy-<名称>` 的只读来源宏，与工作台本地宏合并展示 | 保持主界面存储格式兼容，同时给流程节点稳定引用。 |
| 同名冲突 | 工作台本地宏 ID 优先；主宏库条目使用独立 `legacy-` ID | 既不会覆盖用户的工作台版本，也不会令既有宏消失。 |
| 校验计算 | 纯前端确定性模块，先严格解析偶数字符的 HEX 主体，再按算法追加字节 | 无网络/串口副作用，结果可用标准向量直接验证。 |
| 字节序 | Modbus 与 CRC32 使用小端；CCITT/XMODEM 使用大端；CRC-8 单字节 | 明确常见协议惯例，避免用户从字节序中猜测。 |

## Risks and mitigations

| 风险 | 缓解或验证方式 |
| --- | --- |
| 旧宏没有稳定 ID | 合成带前缀的稳定 ID，并在流程执行时拍摄完整宏快照。 |
| 重复追加校验码 | 计算动作显式追加，主界面会关闭旧的 Modbus 发送时追加开关。 |
| 非法 HEX 被静默修改 | 计算函数拒绝空、奇数字节或含非 HEX 字符的输入；UI 保留原值并提示。 |

## Out of scope

CRC 参数自定义、接收报文自动验 CRC、以及向真实设备自动执行流程。
