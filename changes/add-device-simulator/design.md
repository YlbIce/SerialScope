# Design: add-device-simulator

| 决定 | 选择 | 理由 |
| --- | --- | --- |
| 执行位置 | Renderer 经现有 Main IPC 调用 `serial.send` | 不新增公开 Pipe RPC，也保留 Main 单客户端边界。 |
| 两实例模型 | 模拟实例打开虚拟串口的一端，测试实例打开另一端 | 与 COM10/COM11 的真实测试拓扑一致。 |
| 多窗口仲裁 | Main 指定主窗口或独立模拟窗口唯一拥有应答权 | 防止广播 RX notification 后多窗口重复回复。 |
| Modbus | 03/04 随机寄存器；06/16 标准回显 | 提供常见可用的从站反馈，不假装完整协议栈。 |

自定义规则优先于内置规约，采用完整 HEX 精确匹配；`*` 可匹配任意帧。所有回复都在已启用、已打开串口且拥有执行权时才会发送。
