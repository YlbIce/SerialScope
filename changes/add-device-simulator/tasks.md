# Tasks: add-device-simulator

## 场景—验证映射

| 场景 | 验证 | 命令或步骤 | 失败边界 |
| --- | --- | --- | --- |
| 自定义规则 | 可见 Electron + 原生 COM 辅助程序 | 打开 COM11，COM10 发送 `41 42` 并读取 `CA FE` | 无回复、回复重复或错误字节 |
| AT 内置 | 同上 | COM10 发送 `AT` 并读取 `OK\r\n` | 无响应或行尾不正确 |
| 随机/Modbus | Renderer 算法断言 | 随机模板格式及 Modbus 03 回复长度/结构 | 模板未替换或响应无效 |
| 多窗口 | Electron UI | 打开非模拟独立窗口后不重复回复 | 广播导致多次串口写入 |
| 生产窗口仲裁 | production Main + COM10/COM11 | 打开独立模拟窗口后只收到一份回复，关闭后主窗口恢复 | 多窗口重复回复或无法恢复 |
