# Proposal: prepare-release-and-external-validation

## Why

生产发布仍缺 Windows 安装包、签名、自动更新、真实跨会话验证、正式 LGPL 审查和真实设备回归。这些不能由开发机或模拟器替代，必须形成受控 L3 闸门。

## What

- 建立 9.5–9.8 的可审计发布、合规和外部验证清单及机器检查。
- 在具备证书、更新源、第二 Windows 会话、法务结论及设备授权后，按清单执行并将证据回填本 change。

## Non-goals

- 不自动发布、签名、上传更新或向真实设备发送任何报文。

## Acceptance

1. 发布、跨会话、LGPL 和真实设备每项均有明确输入、责任人和证据要求。
2. 没有人工授权或外部实测证据时，状态不能标为完成或归档。

## Risk tier

`L3` — 涉及发布、签名、跨会话安全边界、法务和真实设备。所有外部动作都需人工闸门。
