# Design: prepare-release-and-external-validation

## Decisions

| 决定 | 选择 | 理由 |
| --- | --- | --- |
| 发布能力 | 先锁定依赖/配置，再在隔离测试通道构建、签名和更新验证 | 证书及更新源不能由开发者假设。 |
| 跨会话 | 使用真实同 SID 第二会话和不同 SID 会话 | 单元测试不能证明 Windows 会话边界。 |
| 许可证 | 由法务书面结论决定交付条件 | 工程检查不能取代法律意见。 |
| 物理设备 | 读取优先、写入单独二次确认 | 维持 L3 物理安全边界。 |

## Risks and mitigations

| 风险 | 缓解 |
| --- | --- |
| 凭据泄露 | 仅通过受控签名通道传递，文档和诊断禁止记录。 |
| 将模拟器结果误认为现场验证 | 清单要求设备/授权/观察证据。 |
| 法务/账户缺失造成假完成 | evidence 必须为 blocked/not-run，保持活动。 |

## Out of scope

选择云签名供应商、更新托管供应商或变更真实设备配置。
