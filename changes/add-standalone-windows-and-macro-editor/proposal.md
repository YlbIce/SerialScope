# Proposal: add-standalone-windows-and-macro-editor

## Why

用户需要只使用趋势、规则或宏时能单独打开相应模块；当前宏仅有固定快捷按钮，不能编辑、保存或管理。

## What

- Main 进程可打开独立的终端、趋势、规则和宏窗口，并向所有窗口广播串口通知。
- 模块窗口通过同一受限 Preload / Main IPC 调用后端，不直连 Named Pipe。
- 宏支持新增、编辑、删除、本地保存、导入配置后恢复及一键执行。

## Non-goals

- 不使宏自动在真实设备上运行；执行仍要求串口已由用户打开。
- 不实现模拟下位机自动应答。

## Acceptance

1. 每个功能页可作为独立窗口打开，且收到同一后端的串口状态/收发通知。
2. 宏编辑结果持久化到本地配置，重新加载后可见并可执行。

## Risk tier

`L2` — 涉及 Main/Renderer IPC、多窗口生命周期与可观察交互，公开串口 RPC 契约不变。
