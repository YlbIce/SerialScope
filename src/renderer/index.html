使用说明

规则会同时匹配日志的文本内容和 HEX 字符串。表达式使用 JavaScript 正则语法，不区分大小写；如果表达式非法，保存时会提示错误。

关闭规则后不会继续命中新日志；保存规则会立即重新计算已有日志的命中和高亮。

示例：ERROR|FAIL|异常 匹配错误，^\\s*\\{.*\\}\\s*$ 匹配 JSON 帧，01 03 可匹配 Modbus 读保持寄存器响应。
